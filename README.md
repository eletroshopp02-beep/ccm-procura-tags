# Manutenção Pro Industrial

PWA responsivo em português, visual preto/azul, cadastro local de TAGs e áreas/CCMs, referência resumida CFW11, testes de resistência e megômetro, fechamentos didáticos de motores, calculadoras, histórico e backup JSON.

## Publicar como PWA
GitHub → Settings → Pages → Deploy from a branch → main → /(root). Após publicar HTTPS, Android: Chrome → Instalar app; iPhone: Safari → Compartilhar → Adicionar à Tela de Início.

## Limitações
Dados ficam no armazenamento local do navegador, sem login nem sincronização. Base de falhas CFW11 parcial. PDF integral do manual não está incluído nesta substituição; adicione o documento autorizado em manuais/Manual_Programacao_CFW11_V3_1X_PT.pdf. Fechamentos são referências didáticas e devem ser conferidos com placa/diagrama do fabricante.
